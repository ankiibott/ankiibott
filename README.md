## 🚀 Featured Projects

<div align="center">

### 🔥 [Forest Fire Prediction](https://github.com/ankiibott/Forest_fire_prediction)
*Hybrid Deep Learning model for spatiotemporal wildfire forecasting*
- **Tech Stack:** Python, TensorFlow/Keras, ConvLSTM, U-Net, NetCDF, Rasterio
- **Features:** 3-hour fire progression forecasting, 6-hour historical sequence analysis, Automated NetCDF preprocessing pipeline.
- **Impact:** Provides direct spatial intelligence for GIS-based disaster management systems to prevent wildfire spread.

### 🏛️ [USAS: UIDAI Smart Allocation System](https://github.com/vishalbarai007/UIDAI-Datathon)
*Predictive logistics framework for Aadhaar 'Last Mile' administration*
- **Tech Stack:** Python, HistGradientBoosting, Scikit-learn, Streamlit, Pandas
- **Features:** Pincode-level demand forecasting, 'Platinum Merge' ETL pipeline (1.5M+ rows), Statistical 'Fraud Radar' for anomaly detection.
- **Impact:** Optimizes mobile camp allocation and detects high-activity spikes (>500%) to improve service transparency.

### 🧹 [DZap: Secure Drive Wiper for Linux](https://github.com/AceofStades/DZap-linux)
*High-security data destruction utility for Linux environments*
- **Tech Stack:** C, Bash, Linux System APIs, Cryptography
- **Features:** Implementation of secure wiping algorithms, low-level disk access, optimized for Linux filesystem security.
- **Impact:** Ensures permanent data removal to prevent unauthorized recovery, enhancing privacy for Linux power users.
